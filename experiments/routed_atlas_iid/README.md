# Graph-Routed Atlas MPC Baseline

This directory is a model-based comparison baseline, not the main DeePC result.
The local controller fits affine state-space dynamics and uses MPC. See
`../routed_deepc_iid/` for the behavioral-column DeePC formulation.

This experiment adds an offline chart-transition graph to the stitched affine
Atlas controller. The graph is learned only from transitions generated by IID
random actions. Online control plans through fixed chart nodes; it never
retrieves a fresh trajectory neighborhood.

The controller has three levels:

1. A graph route chooses the next fixed state chart.
2. Local affine dynamics MPC moves toward the chart's random-state medoid.
3. A three-step local regulator is latched near the target or on arrival at the
   goal chart.

The recommended hybrid uses 65% waypoint MPC action and 35% of the aggregate
mean random action observed for the requested chart transition. This edge
action is a chart-level statistic over many random transitions, not an action
sequence from a successful trajectory.

## Fairness

- Uses the same frozen 200-by-200 IID random-action library.
- The audit finds zero stabilized offline episodes.
- Evaluation seeds are outside the offline seed range.
- No online nearest-trajectory selection is performed.
- No IK, hand-coded PD, expert action, stabilizing trajectory, or feedback
  fallback is used.
- Goal branches use isolated random states. Their source episodes have different
  environment targets, and no adjacent actions or trajectories are reused.

## Formulation Comparison

| Formulation | Evaluation | Strict successes | Interpretation |
| :--- | :--- | ---: | :--- |
| Coarse waypoint graph | Original 8 seeds | 8/8 | Pure chart-medoid MPC routing |
| Coarse aggregate edge action | Original 8 seeds | 7/8 | Seed 42 fails; edge means alone are insufficient |
| Coarse hybrid, compatible branch | Original 8 seeds | 8/8 | Waypoint and edge statistics complement each other |
| Coarse hybrid, closest-XY branch | Combined 28 seeds | 27/28 | Broadest single fixed formulation |
| Fine 256-chart waypoint graph | Seed 29 | 1/1 | Resolves the remaining folded-arm topology case |

## Primary Artifacts

`candidate_waypoint_switch7cm/` is the clean 8/8 waypoint result. Every one of
its 2,560 QPs is optimal. The largest final-100 distance is 8.24 mm.

`robust28_coarse_hybrid/` is the broad evaluation. It succeeds on all original
seeds and 19 of 20 previously untouched seeds. All 8,960 QPs are optimal. Seed
29 is the only failure, settling at 78.5 mm.

`probe_seed29_graph256_thr1/` contains the separately declared fine-atlas seed
29 result. It holds at 2.31 mm over its final 100 steps. The fine graph is not
silently selected by the broad controller, so this is evidence for a future
automatic multiresolution gate rather than a 28/28 single-controller claim.

The dwell criterion is:

- final-30 mean below 1 cm and maximum below 2 cm;
- final-100 mean below 1 cm and maximum below 2 cm.

For almost every successful broad-evaluation seed, the final 100-step distance
is numerically constant. Seed 22 has the largest final-100 variation and still
remains between 5.97 mm and 10.47 mm.

Run the recommended coarse MPC baseline with:

```bash
conda run -n gym-robotics-mujoco python src/routed_atlas_experiment.py \
  --output-name reproduction
```

The runner defaults to hybrid routing, closest-XY goal-branch selection, a 7 cm
local handoff, and latched local regulation.
