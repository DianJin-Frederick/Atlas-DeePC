# Graph-Routed Fixed-Chart Atlas-DeePC

This is the current main Atlas-DeePC experiment. It retains the useful chart
transition graph from the MPC exploration, but the controller itself is DeePC:

```text
[u_ini; u_future; y_ini + sigma; y_future] = h_bar + V_r g
```

Here `h_bar + V_r g` is a rank-60 affine SVD representation of columns from the
current offline Hankel chart. The optimized future is therefore a linear
combination of a fixed behavioral data matrix. No `A`, `B`, or `c` dynamics are
fitted. The graph selects waypoint references; it does not generate actions.

## Primary Results

| Artifact | Seeds | Strict successes |
| :--- | :--- | ---: |
| `heldout100_frozen_target_separated/` | 111 through 210 | 88/100 |

The single frozen formulation succeeds on 88 of 100 untouched seeds. A
success must pass both dwell checks: final-30 and final-100 mean distance below
1 cm, with maximum distance below 2 cm in each window. Every one of the 32,000
saved DeePC solves is optimal. The 95% Wilson confidence interval is 80.2% to
93.0%.

Each primary directory also contains `multi_seed_distance.png`; the development
directory includes detailed seed 1 and seed 3 tracking plots, and the held-out
directory includes a seed 10 example.

The project-root `routed_deepc_experiment.ipynb` is the executed experiment
record. It contains aggregate statistics, the complete failure table, ten
spatially representative success videos, and three additional diagnostic
MuJoCo replays. Every displayed replay is exactly verified.

The `exploration/` directory contains formulation and hyperparameter probes;
`diagnostics/` contains post-hoc failure analysis. Neither is primary evaluation
evidence.

## Formulation Exploration

The initial seed-1 comparison used the same frozen atlas and 160-step horizon:

| Behavioral matrix | Final-30 mean | Strict success |
| :--- | ---: | :---: |
| Raw columns, current chart | 16.37 mm | no |
| Raw columns, current/next overlap | 5.23 mm | yes |
| Rank-100 SVD, current chart | 3.39 mm | yes |
| Rank-100 SVD, current/next overlap | 20.43 mm | no |

Raw overlap establishes that a direct Hankel-column formulation can work, but
its QP is much larger. Current-chart SVD retains the behavioral span in a compact
orthonormal coordinate system and generalized better than overlapping SVD
charts. A subsequent multi-seed rank sweep selected rank 60 for the frozen
evaluation.

## Fairness

- The offline library contains 200 episodes generated by IID random actions.
- The audit finds zero offline episodes stabilized within 1 cm.
- Evaluation seeds are outside the offline collection seed range.
- Goal configurations are isolated random states from episodes whose targets
  are at least 6 cm from the online target; no neighboring action or trajectory
  is reused.
- There is no online nearest-trajectory selection, IK controller, feedback
  blend, expert action, fitted dynamics, or fallback controller.

## Reproduce

```bash
conda run -n gym-robotics-mujoco python src/routed_deepc_experiment.py \
  --atlas-path experiments/routed_deepc_iid/heldout100_frozen_target_separated/behavioral_atlas.npz \
  --seeds {111..210} \
  --output-name heldout100_reproduction
```

This reproduces the frozen rank-60 current-chart affine-SVD formulation on the
100 untouched held-out seeds. The 13 displayed videos are already stored with
the primary results and verified by the notebook.
